# 하루이음 스터디 운영 적용

하루이음 스터디는 기존 Firebase 프로젝트의 Auth UID, 공개 닉네임·핸들, 풀이 기록과 담벼락 게시물 경로를 이어 사용한다. GitHub Pages를 당분간 사용한다. 테스트는 운영과 분리된 Firebase 프로젝트 또는 에뮬레이터에서 진행한다.

## 적용과 검증

1. 기존 서비스의 필기·복습을 보존해야 하는 사용자는 전환 전에 **프로필 → 내 정보 관리**에서 브라우저 백업을 내보낸다. 주소의 호스트가 달라지면 새 주소에서 가져온다. 동일한 Firebase 프로젝트로 로그인하면 기존 계정 풀이 기록을 조회할 수 있다.
2. 개발 Firebase에 [Firestore 규칙](../firestore.rules)과 [인덱스](../firestore.indexes.json)를 적용한다. 개인 시간표·필기, 그룹 초대·승인, 게시물과 댓글, 기존 회원 로그인과 풀이 기록을 확인한다.
3. 운영 주체와 연락 창구를 정하고 이용약관과 개인정보 처리방침의 공개 HTTPS 주소를 준비한다. 연령 확인 방식, 그룹 공유·신고·탈퇴, 기존 SNS 링크와 게시물의 처리 방안을 확정한다. 소개 사이트가 있으면 수집·가입 안내를 실제 운영에 맞춰 수정한다.
4. Firebase Console에서 `harueumConfig/release` 문서를 만든다. 아래 값은 공개 설정이며 비밀 키는 넣지 않는다. `policyVersion`은 실제 공개 문서의 버전을 사용한다. 값이나 주소가 없으면 신규 가입 화면이 닫힌다.
5. 이름과 도메인을 확정하기 전에 상표·스토어·SNS 중복을 확인한다. 커스텀 도메인을 쓰는 시점에 Pages·DNS를 연결하고 Firebase Authentication 승인 도메인을 추가한다. 기존 Firebase 설정, Pages 경로와 미리보기는 [배포 문서](DEPLOYMENT.md)를 참고한다.
6. 운영 반영 때는 Firebase 규칙과 Pages 배포를 함께 계획한다. 새 규칙을 먼저 게시하면 기존 광장 화면의 동작도 새 접근 제한을 받는다. 새 클라이언트는 `main`의 Pages 배포로 갱신한다.

| 필드 | 형식 | 역할 |
| --- | --- | --- |
| `policyVersion` | 문자열 | 현재 이용약관·개인정보 처리방침 버전 |
| `termsUrl`, `privacyUrl` | HTTPS 주소 | 가입·기존 계정 확인에 사용하는 실제 문서 |
| `groups` | 불리언 | 승인형 학급·스터디 그룹 개설 및 가입 |
| `groupStories` | 불리언 | 승인된 구성원에게 그룹 글·댓글 공개 |
| `plaza` | 불리언 | 운영 문서를 확인한 학생 계정에 기존 담벼락 공개 |

그룹과 광장은 기본적으로 닫혀 있고, 광장은 그룹과 그룹 이야기가 먼저 활성화된 경우에만 열린다. 세 항목은 운영 검토가 완료된 뒤 순서대로 켠다. 운영 문서가 바뀌면 기존 회원은 **나**에서 새 버전을 확인할 수 있다.

### 학교 연동

[NEIS Worker](../workers/neis/worker.js)는 학교 코드로 교육청을 찾고 공개 시간표·점심 급식·학사일정을 조회한다. 계정 UID와 인증 토큰은 전송하지 않는다. 사용자 선택으로 입력한 학교 코드·학년·반과 조회 날짜는 Worker와 NEIS가 처리한다. 연결이 꺼져 있거나 학교 정보를 입력하지 않은 경우에는 개인 일정을 사용할 수 있다.

1. NEIS API 키를 발급받는다.
2. `workers/neis`의 `wrangler.toml`에서 `ALLOWED_ORIGINS`에 실제 웹 앱 출처를 등록하고, Cloudflare Workers에 `NEIS_API_KEY`를 Secret으로 설정한다. Worker를 배포한다.
3. GitHub Actions 저장소 변수 `VITE_NEIS_WORKER_URL`에 Worker의 HTTPS 주소를 등록한다. 개발 미리보기에는 `VITE_DEV_NEIS_WORKER_URL`을 사용할 수 있다.
4. 실제 학교 코드로 오늘의 교시·급식과 다음의 학사일정을 확인한다. 학교 코드와 일정이 없는 날도 확인한다. NEIS 호출량에 대비한 Cloudflare의 외부 요청 제한과 캐시 동작은 운영 환경에서 확인한다.

## 남은 구현과 결정

| 영역 | 상태 |
| --- | --- |
| 학습 검증 | 세션의 점수·XP가 일치하면 개인 합계에 반영한다. 기존 개인 풀이 기록은 계속 제공하고 공개 랭킹은 닫아 둔다. |
| 학원·그룹 공유 | 학급·스터디의 초대 코드, 승인, 글·댓글, 그룹장 이양과 구성원 확인, 운영자 신고가 있다. 학급 자동 탐색과 규모 구간, 학원 운영 주체 확인과 일정 배포, 1:1 이야기, 그룹 반응·리포스트, 공유 확대·축소 이력과 공부 시간·상세 통계는 후속 구현이다. |
| 이야기 운영 | 기존 담벼락의 읽기·작성·댓글·리포스트는 광장에서 계승한다. 광장에 첨부한 학습 문제는 텍스트로 저장된다. 동일 문항을 물음샘에 다시 여는 방식, 링크 안내·개인 연락 탐지의 운영 기준, 운영자 신고 처리 화면, 기존 공개 SNS 링크 문서 정리는 공개 전에 완료해야 한다. |
| 법률과 연락 | 이용약관·개인정보 처리방침 및 가입 동의의 최종 문구, 미성년자 보호와 그룹 권한, 삭제·보존, 신고 운영 방식, 연락 창구는 운영자가 확정한다. |
| 운영 검증 | GitHub Pages 운영 배포 및 실제 Firebase·NEIS 연결, iOS·Android 설치와 화면 읽기 보조기술은 운영 환경에서 확인한다. |

신고 기록은 기존 광장 신고 경로와 `users/{uid}/harueumGroupReports/{reportId}`에서 확인할 수 있다. 운영자는 신고에 필요한 범위로만 원문에 접근하는 절차를 정한다. SNS 링크가 남은 기존 프로필 문서는 소유자만 읽을 수 있다. 소유자가 프로필을 저장하거나 운영자가 링크 값을 정리하면 공개 프로필 조회가 다시 가능하다.

## 추가 운영 설정

- 학습 Worker는 `workers/learning`에서 배포한다. 기존 Firebase 프로젝트의 `FIREBASE_PROJECT_ID`, 앱 웹 API 키 `FIREBASE_API_KEY`, 사이트 출처 `ALLOWED_ORIGINS`를 설정한다. Firestore 쓰기에 필요한 권한으로 제한한 서비스 계정 JSON을 Worker Secret `FIREBASE_SERVICE_ACCOUNT`에 저장한다. Pages 변수 `VITE_LEARNING_WORKER_URL`과 개발용 `VITE_DEV_LEARNING_WORKER_URL`은 해당 환경의 Worker 주소를 사용한다.
- 세션 종료 XP 타일은 해당 세션 획득량을 표시한다. 일치한 세션만 계정 합계에 한 번 합산된다. ‘검증을 통과하지 못해 기록에 반영되지 않았어요’ 이후 접수된 이의는 Firebase 콘솔의 `users/{uid}/verificationAppeals/{sessionId}`에서 확인한다. [세션 검증 설계](SESSION_VERIFICATION.md)
- 기존 그룹이 있는 운영 프로젝트에서는 `harueumGroups`의 실제 소유자로 `users/{uid}/harueum/ownedGroups`의 `count`를 이관한다. 운영 확인 후 `harueumConfig/release.ownershipIndexed`를 `true`로 설정하면 학생·교사 유형 전환이 열린다. 이관이 안 된 기존 그룹은 소유권 이양이 실패할 수 있다. 그룹장 유형 전환 시 장기 처리는 미정이다.
- 상세 통계는 집계 방식이 확정될 때까지 생성하지 않는다. 허용된 스터디 그룹에 이양 후 접근 규칙을 준비했으며, 새 그룹장에게는 해당 이양에 대한 확인 전까지 회원 상세를 제공하지 않는다. 총 공부 시간은 보류 상태다.
- NEIS Worker는 Cloudflare 요청 제한 바인딩을 사용한다. 기본값은 IP당 지역별 분당 30회다. 권한·약관·외부 연락 정책은 기존 공개 조건을 모두 충족한 뒤 활성화한다.

GitHub 저장소 설명은 “하루이음 스터디 · 시간표와 일정, 수학·영어 학습, 그룹 이야기를 연결하는 학생용 PWA”를 사용한다. 웹사이트는 Pages 주소를 연결하며 토픽은 `education`, `pwa`, `firebase`, `study-planner`를 사용한다.
