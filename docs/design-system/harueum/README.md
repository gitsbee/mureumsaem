# Harueum Design System 1.0 · 개정 24

하루이음 스터디 · Project Harueum Study  
**고등학생부터 N수생까지, 흩어진 하루를 하나로 잇다**

고1~고3, N수생과 재학습자가 일상, 일정, 학습, 교류를 오가는 공통 디자인 시스템이다. 물음샘은 수학·영어 학습 영역의 이름으로 사용한다. 이야기는 소통 영역이며 광장은 그 안의 전체 회원 공개 공간이다. 세 영역은 동일한 토큰과 컴포넌트를 사용한다.

## 1. 원본 대조와 적용

통합 기획안 1.0이 제품 정책과 정보 구조의 기준이다. 물음샘 v4 ZIP의 `pulim-tokens.css`, `pulim-components.css`, 토큰·아이콘 JSON, SVG, 수식 렌더러, README와 단일 HTML을 대조했다. ZIP과 단일 HTML의 가이드 바이트가 일치했다. 하루이음은 첨부된 Figma 벡터 내보내기 `Section 1.svg`의 모바일 화면 4종과 일정 행, 하단 메뉴, 상황 행동 예제를 기준으로 분석했다. 편집 가능한 Figma의 컴포넌트 속성, 변수, 프로토타입 연결은 벡터 내보내기에서 확인할 수 없다.

v4 README 첫 문단에는 눌림 글자색 전환을 ‘밝은 테마에서만’ 적용한다고 적혀 있다. 상태 표와 실제 CSS의 동작에 맞춰 **밝게·종이는 흰색으로 전환, 어둡게는 밝은 글자색 유지**를 기준으로 삼는다. 단일 HTML에 v4의 토큰 CSS와 컴포넌트 CSS, 아이콘 74개를 그대로 포함했다. 오늘 탭의 모래시계와 화면별 학교·과목·일정·메타데이터 아이콘을 v4의 24px 규격으로 확장했다. 공통 외형은 v4 CSS를 사용한다. 오늘은 진행 중인 수업에 v4 정보색 외곽선을 적용한다. 다음은 파란 구분선 가운데 ‘오늘’을 배치한다.

- 전역 탐색의 현재 항목은 모바일에서 v4 2px 밑줄, PC에서 v4 정보색 2px 테두리로 표시한다. 키보드와 보조기술은 이름이 있는 링크와 `aria-current="page"`를 사용한다.
- 포커스는 해당 요소의 현재 상태 위에 2px 외곽선과 4px 간격으로 표시한다. 포커스와 선택을 동시에 볼 수 있어야 한다. 포커스 토큰은 v4 파랑을 사용하고 조작 표면과 주변에서 각각 대비를 검증한다. 스크롤 경계에서는 링을 안쪽에 배치할 수 있다. 수업 필기·기록·할 일의 텍스트 입력 면은 커서로 포커스를 표시한다. 나머지 조작의 키보드 포커스는 v4 규칙을 따른다.
- 밝게·어둡게는 Noto Sans KR 계열, 종이는 Noto Serif KR 계열을 사용한다. 테마는 SVG 아이콘과 이름을 병기한 중립색 v4 라디오 버튼으로 선택한다. 탭 라벨 표시 스위치의 켜짐과 효과음 슬라이더의 값 채움에는 v4 초록을 사용한다. 테마 선택 버튼과 단독 아이콘 버튼은 테마의 기본 잉크를 사용한다. 하루이음과 수학·영어 풀이는 테마 선택을 공유한다. 어느 화면에서든 테마를 변경하면 공통 설정에 저장한다. 시스템 테마는 하루이음에서 운영체제 설정을 한 번 해석해 메인·풀이·결과에 같은 밝기 모드를 적용한다. HTML은 설치 글꼴과 v4 대체 글꼴을 사용한다.
- 일반 글자는 4.5:1, 큰 글자는 3:1이다. 아이콘은 4.5:1을 목표로 하며 최소 3:1을 유지한다. 조작 테두리 대비는 비적용이며 조작 식별에는 아이콘과 텍스트를 쓴다. 키보드 포커스 링과 선택·눌림 표시는 인접 면과 3:1을 유지한다. [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## 3. 학생 화면과 반응형 규칙

| 탭 | 제목 | 정보 위계와 첫 행동 |
|---|---|---|
| 오늘 | 오늘 | 날짜별 시간표. 수업과 점심을 시각순 카드로 배열하고 현재 수업을 펼침. 하단 행동 카드의 연필 아이콘으로 마크다운 필기 열기 |
| 다음 | 다음 | 월 → 날짜 → 학사일정·시험·과제. 날짜와 해당 일정을 같은 카드 안에 배치. 하단 행동 카드의 책 아이콘으로 범위 복습 열기 |
| 물음샘 | 물음샘 | 수학·영어, 오답 복습, 북마크로 바로 진입. 최상단 학습 현황의 스트릭·레벨·리그는 각 지표색을 채운 두꺼운 상단 띠에 이름을 표시한다. 아래에는 아이콘과 Medium 값을 나란히 둔다. 2px 테두리와 상단 띠에는 밝은 테마와 다크 모드에서 동일한 v4 역할색을 쓴다. 학습 기록 제목에는 기록 아이콘을 표시한다. 자세히에서 과목별 누적 시간을 확인한다. 하단에서 과목 아이콘과 Medium 과목명을 확인하고 타이머를 시작하면 경과 시간을 표시한다 |
| 이야기 | 이야기 | 그룹 목록에서 가입 또는 입장하고, 게시글은 그룹 내부에서 읽는다. 행동 바의 그룹·광장 탭은 고정 위치에 아이콘과 이름을 항상 표시한다. 광장 패널은 게시글 목록으로 바로 시작한다. 오른쪽 고정 슬롯에는 그룹에서 더하기(새 그룹 만들기), 광장에서 연필(새 글 작성)을 표시한다. 게시글 아래에 좋아요·싫어요·댓글·리포스트 아이콘과 숫자를 둔다. 더보기 메뉴는 같은 행의 오른쪽 끝에 놓는다 |
| 나 | 나 | 공용 카드 안쪽 여백 16px를 적용한 ‘프로필’과 오른쪽 편집 아이콘 → 같은 줄의 닉네임과 회색 핸들 → 소개 → 설정과 디자인 예제. 편집 버튼의 터치 영역과 제목 행 높이를 별개로 유지해 카드의 기본 상단 여백을 맞춘다 |

| 1080px 이상 | 좌측 메뉴 유지. 오늘·다음·물음샘·이야기는 본문과 하단 행동 카드를 같은 폭으로 맞춤. 나머지 화면은 콘텐츠 유형에 적합한 폭 사용 |
| 좁고 낮은 화면 | 본문과 하단 행동 카드를 서로 다른 행으로 배치. 화면 높이가 낮으면 행 간격 축소. 수식과 정밀 필기 영역은 필요한 국소 확대·스크롤 지원 |

예제는 가용 너비 720px에서 하단 메뉴를 좌측 메뉴로 바꾼다. 좌측 메뉴의 머리에는 큰 모래시계와 Bold 29px ‘하루이음’을 표시하고, ‘나’는 메뉴의 맨 아래에 둔다. 글자 확대와 분할 화면에서도 레이아웃을 검증한다. 모바일 실제 순서는 오늘(모래시계), 다음(달력), 물음샘(책), 이야기(말풍선), 나(사람)이다. 전역 이동은 이름이 있는 링크와 `aria-current="page"`를 사용한다. 화면 전환 후 제목에서 문서 탐색을 시작할 수 있고 본문 바로가기를 제공한다.

오늘은 일 단위, 다음은 월 단위로 목록의 양쪽 끝을 확장하고 스크롤바는 숨긴다. 이전 구간을 붙이면 보고 있던 위치를 유지한다. 어제부터 내일까지의 범위를 벗어나면 오늘 화면 오른쪽 하단에 시계 아이콘과 ‘오늘로’를, 지난달부터 다음달까지의 범위를 벗어나면 다음 화면 같은 자리에 ‘이번달로’를 표시한다. 탭에 진입하거나 해당 탭을 다시 누르면 오늘은 오늘 표제부터, 다음은 이번 달 표제부터 보여 준다. 학습을 마친 뒤 돌아갈 때에는 직전 스크롤 위치를 복원한다. 일정 영역이 축소되며 빠지고 대상 목록이 나타난다. 운영체제의 모션 감소를 설정하면 즉시 전환한다. 다섯 탭 제목은 중앙 정렬에 v4 본문 크기 17px와 제목 굵기 700을 쓰고, 날짜 구분 제목에는 400과 기본 글자색을 쓴다. 다섯 탭은 화면 너비별로 동일한 상단 여백을 쓴다. 과목명·일정명·그룹명·사람 이름은 Medium 500으로 표시한다. 날짜 구분은 기준일 주변에 어제·오늘·내일, 그 밖의 날짜에 M/D 요일을 쓴다. 카드 안의 날짜 태그는 회색을 유지한다. 오늘의 진행 수업은 테두리, 다음의 오늘은 파란 2px 구분선과 중앙의 Medium 텍스트로 기준 위치를 표시한다. 모바일에서 행동 카드는 전역 탭바 위에 8px 간격을 두고 배치한다. 각각 독립된 표면을 사용한다. 행동 카드의 바깥 래퍼는 투명하고, 안쪽 카드에 한 번만 배경을 적용한다. 카드 안쪽 간격은 세로 8px, 가로 16px다. 좌우 바깥 여백은 8px이며 콘텐츠 최대 폭을 따른다. 낮은 화면에서는 세로 안쪽 간격만 4px를 쓴다. 오늘과 다음의 시간표·일정은 같은 펼침 카드, 세로 간격과 상세 내용 최소 높이를 사용한다. 두 하단 행동 카드 또한 본문 두 줄을 기준으로 높이와 패딩을 맞추고, 과목 아이콘과 Medium 과목명을 병기한다. 넓은 화면에서 행동 표면과 좌측 메뉴는 화면의 서로 다른 위치에 표시한다. 예제 날짜와 수업 진행률은 시연용 고정 데이터다.

집중 학습 예제는 수학 기본 두 문제와 확장 한 문제, 영어 두 단어를 사용한다. 일반 화면·집중 학습·학습 완료는 한 문서 안에서 같은 v4 스타일시트와 아이콘을 사용한다. 집중 학습에 진입하면 전역 탐색을 접는다. 수학과 영어는 같은 위치 규칙으로 건너뛰기·공유·풀이 설정을 제공한다. 비로그인 상태에서는 학습만 제공한다. 공유는 진입한 공간의 공개 범위를 따르며, 북마크는 현재 항목을 브라우저에 저장하고 해제할 수 있다.

| 화면 폭 | 답안·조작 위치 | 필기 도구 |
|---|---|---|
| 720px 미만 | 하단 한 줄에 닫기, 답안 또는 정답 확인, 북마크 순서로 표시. 수학 답안이 포커스를 받으면 양쪽 슬롯이 줄면서 입력이 행 전체를 차지. 공유·건너뛰기·설정은 상단, 단원·진행·콤보 태그는 상단 제목 아래 | 답안 행 바로 위 |
| 720px 이상 | 닫기는 제목 왼쪽, 단원·진행·콤보 태그는 제목과 설정 사이. 답안 또는 정답 확인, 공유, 북마크, 건너뛰기는 문제 바로 아래에 한 행으로 표시 | 문제 아래 풀이 캔버스 상단 |

수학 답안과 정답 확인 아이콘은 한 컨트롤이다. 입력은 v4 본문 크기 17px이고, 화면에 별도 보조 라벨을 두지 않으며 접근성 이름은 ‘답안 입력’이다. Enter 또는 정답 확인 아이콘으로 채점한다. 키보드 입력 조합 중에는 제출을 보류한다. 영어는 뜻을 확인한 뒤 같은 행에서 암기 난도를 고른다. 모바일에서는 어려움·보통·쉬움 아이콘이 기본으로 표시되며 각 버튼의 접근성 이름을 제공한다. 풀이 설정의 영어 탭에서 ‘버튼 항상 라벨링’을 바꿀 수 있다. 설정은 브라우저에 저장한다. PC에서는 난도 아이콘과 라벨을 함께 표시한다. 건너뛴 항목은 정확도 집계에서 제외한다. 필기 영역은 남은 화면을 채우고 획이 아래쪽에 가까워지면 자동으로 확장하며 기존 획의 위치를 유지한다. 필기 도구로 펜·지우개·되돌리기·지우기를 조작한다. 문제 위쪽이 화면에서 벗어나면 맨 위로 올라가기 버튼을 표시한다. 선택된 필기구는 v4 정보색 2px 테두리와 `aria-pressed`로 표시한다. 화면 키보드가 표시되면 보이는 높이에 맞춰 풀이 영역을 조정한다. 운영체제의 모션 감소 설정을 적용한다.

풀이 설정에는 화면·입력·소리·지원·과목 탭을 둔다. 모바일에서는 설정 창을 전체 화면으로 펼친다. 화면 탭에서 테마와 기기의 전체화면 표시를 조정한다. 수학 입력에는 펜 전용과 압력 감도를, 영어 입력에는 세벌식 390을 제공한다. 소리 탭에서 효과음을 켜고 음량을 조정한다. 수학의 확장 문제와 영어의 수동 단어 범위는 새 연습을 열 때 적용한다. 그룹에서 연 문제는 원본 그룹 안에서 공유한다. 일반 문제 공유에서는 게시 공간을 선택하거나 기기의 공유 창으로 문제 텍스트를 보낼 수 있다. 기기에서 공유 창을 사용할 수 없으면 복사 경로를 제공한다.

수학 답안은 원본 물음샘과 동일하게 한 줄짜리 일반 텍스트 편집 영역으로 구현하고 기기의 문자 키보드를 사용한다. 풀이 본문은 화면 전체 폭에서 세로로 스크롤되며 문제와 필기의 최대 너비는 안쪽 여백으로 유지한다. 답안에 포커스가 갈 때 접힌 버튼은 가로 스크롤 영역을 만들지 않는다. 예제의 채점은 정수·소수·분수와 기본 제곱근 표기를 지원한다. 파란색 테두리로 현재 상태를 표시할 때 같은 색을 10% 불투명도로 내부에 채운다. 일정의 월 표제는 예제 기준일과 같은 연도이면 월만 표시한다.

학습 종료 화면의 제목은 5탭과 동일한 스타일의 ‘학습 완료’다. XP·콤보·정확도는 ‘확인’ 바로 위에 공통 통계 타일로 배치하고, 타일 묶음 뒤에 별도의 표면을 두지 않는다. 콤보는 풀이와 결과에서 같은 과녁 아이콘과 v4 정답 초록을 사용한다. ‘확인’은 직전 탭과 스크롤 위치로 돌아간다.

수업 필기는 PC에서 중앙 모달 창, 모바일에서는 좌우 여백 없는 전체 폭 하단 카드로 열린다. 상단의 작성 면에 바로 타이핑하고, 날짜·교시·과목은 하단 태그에 한 번만 표시한다. 필기·기록·할 일은 화면 아래에 동일한 폭과 위치로 고정된 탭이다. 아이콘과 이름을 표시하고, 선택한 탭의 패널 하나만 표시한다. 필기 탭은 제목·목록·인용 구문과 강조·취소선·인라인 코드를 같은 입력 영역에 입력하면서 적용한다. 붙여넣은 마크다운도 같은 영역에서 표시한다. 기록 및 할 일은 별도 입력과 목록을 제공한다. 할 일 패널은 상태 태그를 표시하지 않으며, 새 할 일 입력과 추가 버튼은 목록 아래에 둔다. 빈 목록은 보조 글자색으로 안내한다. 하단의 닫기와 저장은 각각 아이콘과 이름이 있는 동일 너비의 v4 버튼이다. 저장하면 입력 내용을 브라우저에 날짜·교시별로 보관한다. 닫기에서는 임시 입력을 커밋하지 않는다.

## 4. 컴포넌트와 접근성

| 범위 | 컴포넌트 | 상태와 동작 |
|---|---|---|
| 공통 | 버튼·아이콘 버튼·링크 | 기본·호버·눌림·포커스·비활성·처리 중. 순간 실행과 지속 선택의 의미 구별. 선택 토글은 `aria-pressed`, 링크는 목적지 이름. 라벨 버튼은 2px 테두리와 v4 돌출·내입, 면·역할색, 텍스트와 같은 잉크색의 아이콘을 사용한다. 아이콘 버튼은 v4 44px 도구로, 배경·테두리·깊이·화면 텍스트 없이 테마의 기본 잉크와 접근성 이름을 쓴다. 라벨 버튼은 같은 줄에서 동일 너비를 사용하고 모바일의 네 항목 선택은 2×2로 배치한다. 전역 탐색 링크와 상태를 바꾸는 스위치·슬라이더는 해당 컴포넌트 규칙을 따른다. 로딩 중 동작 이름 유지 |
| 공통 | 라디오 카드·필터·전환 | 상호 배타적 값은 네이티브 라디오와 그룹 이름. 필터는 `aria-pressed`. 필기·기록·할 일과 그룹·광장은 `tablist`·`tab`·`tabpanel`을 사용한다. 레이블, v4 밑줄, `aria-selected`로 선택 상태를 알린다. 키보드 Tab은 선택 탭에 진입하고 좌우 방향키와 Home·End는 포커스와 활성 패널을 함께 옮긴다 |
| 공통 | 스위치·슬라이더 | 스위치는 `role="switch"`·`aria-checked`, 46×44px 트랙과 28px 손잡이. 행 전체를 조작하고 켜진 트랙에 v4 초록 적용. 슬라이더는 네이티브 range, 이름·숫자·단위, 방향키와 Home·End, 값에 맞춰 v4 초록 게이지를 갱신. 모션 감소에서도 값과 선택 표식 유지 |
| 공통 | 필드·읽기 전용 정보·폼 오류 | 표시 라벨, 필요 시 `aria-describedby`. 오류 입력에 `aria-invalid`와 가까운 오류 문구. 읽기 전용 정보는 평면 값 또는 실제 `readonly` 필드, 비공개 범위는 v4 아이콘·라벨과 대상 설명. 권한 밖 자료는 표시 데이터에 포함하지 않음 |
| 공통 | 제목·카드·태그·배너 | 카드 자체는 평면. 조작 가능한 카드에만 버튼·링크 의미 부여. 태그는 아이콘과 텍스트를 분리된 요소에 넣고 세로 중심을 맞춘다. 필기·일정·그룹은 동일한 v4 내부 여백·최소 높이·아이콘 크기를 사용한다. 과목·일정·그룹의 대표 아이콘은 역할색을 쓰고 그 밖의 아이콘은 표면의 대비에 맞는 무채색 잉크를 사용한다. 태그 사이는 v4 행의 8px 간격으로 통일한다. 배너는 상태·영향·다음 행동을 구분하고 경과·완료 상태는 `role="status"` |
| 공통 | 펼침·메뉴·확인 대화상자 | 펼침은 의미 있는 요약과 열림 상태. 게시물 더보기는 네이티브 펼침과 버튼 목록을 쓴다. 항목은 44px 높이로 촘촘히 쌓고, 아이콘과 레이블은 왼쪽에 정렬한다. 항목별 테두리와 돌출 효과는 생략한다. 차단 아이콘과 텍스트는 같은 위험 색상을 쓰며, 기본 배경과 가리킴·눌림 배경에서 4.5:1 이상을 확보한다. 취소·닫기는 v4 위험색 테두리와 X·텍스트, 확인·저장은 v4 시작색 테두리와 체크 또는 저장 아이콘·텍스트로 표시한다. 두 라벨 버튼이 함께 있으면 절반씩 같은 너비를 사용하며, 하나만 있으면 행 전체를 채운다. 접근성 이름과 툴팁에도 동작을 명시한다. 대화상자의 제목과 본문으로 대상과 결과를 안내한다. 취소에 기본 포커스를 두고 Escape나 닫기로 실행 지점에 복귀한다. 실행 요소가 사라졌으면 다음 관련 위치로 이동 |
| 학습 | 문제·수식·선택지·답안 | KaTeX 0.19.1 HTML+MathML, `trust: false`. 인라인 수식은 문단 타입, 독립 수식 20px. 곱셈은 `\cdot`. 설명은 일반 텍스트. 긴 수식만 가로 스크롤하며 키보드로 접근 가능. 답안은 순번과 값이 모두 읽히고 정답·오답에 판정 문구 표시 |
| 학습 | 필기 작업대·채점·학습 결과 | 펜·지우개·실행 취소·키보드로 답안 입력. 필기는 배경색과 대비를 유지하고 축소·확대 후에도 도구가 접근 가능해야 함. 채점 판정은 문제 영역에서 표시. 학습 완료는 XP·콤보·정확도를 확인 버튼 바로 위에 표시. 점수·XP가 일치하지 않아 검증 기록이 반영되지 않은 경우에만 경고 표시 |
| 관리 | 검색·필터·데이터 행·일괄 조작 슬롯 | 표는 열 제목·정렬 상태·선택 수와 행 이름 제공. 좁은 폭에서는 정보 라벨이 있는 행으로 재배치. 회차별 선택과 전체 범위 선택의 결과가 분명해야 함. 제공 데이터와 유효 권한 기준으로 동작 노출 |
| 관리 | 가입 검토·정책 편집·이양 | 신청 상태·현재 공유 범위·변경 범위·이양 대상과 결과를 공통 상태와 모달로 표현. 계정 유형, 그룹 내 역할, 학원 운영 주체 확인은 서로 별도 정보 |

교사 가입에는 학교·학원·스터디그룹 중 하나를 표시한다. 학생 가입에는 고1·고2·고3·N수생·재학습을 표시한다. 교사 계정은 그룹 관리용이라는 설명을 붙인다. 교사 UI는 공용 입력·표·행·권한 컴포넌트를 사용하며 내비게이션·대시보드 구조는 교사 UX 명세에서 정한다. 모바일 예제에서 관리 화면은 학생 5탭 없이 검토한다.

## 5. 일정과 시간표

| 요소 | 표시 규칙 |
|---|---|
| 시간표와 일정 | 오늘은 해당 날짜의 수업·점심·보강 등 시간표 항목을 시작 시각순으로 표시한다. 다음은 시험·과제·학사일정을 날짜순으로 표시한다. 비어 있음과 출처별 오류를 구별한다 |
| 카드 | 아이콘과 Medium 이름을 첫 줄, 교시·출처·일정을 구분하는 태그를 둘째 줄에 둔다. 다음 일정에서 D-Day가 있는 경우 해당 태그를, 없는 경우 날짜 태그를 표시한다. 펼친 상세는 항목 아이콘과 이름을 왼쪽, 값을 오른쪽에 맞춘다. 현재 수업은 정보색 2px 테두리로 표시하며 기본으로 펼친다 |
| 출처와 권한 | 학교 태그는 학교 아이콘으로 표시하고, 원본은 외부에서 관리한다. 학원 구분은 건물 아이콘을 사용한다. 학원·기숙학원 그룹은 권한 있는 운영자가 관리하고 구성원은 읽기 전용 구독, 개인은 소유자가 편집. 출처 표시와 편집 권한을 별도 값으로 전달 |
| 읽기 전용·편집 가능 | 읽기 전용에는 v4 아이콘과 라벨, 수정 가능한 일정에는 ‘일정 편집’ 동작. 하나의 원본 ID와 수정 권한을 오늘·다음의 표시에서 공유 |
| 겹침 | 예를 들어 17:00–18:00과 17:30–18:20이 겹치면 17:30–18:00 구간에 ‘일정 겹침’과 두 일정을 나란히 표시. 각 일정의 실제 시간을 유지. 좁은 폭에서는 같은 구간 안의 독립 행으로 줄바꿈 |
| D-Day | 날짜와 상대값을 함께 표시. 미래 `D-3`, 당일 `D-Day`. 날짜가 확정되지 않은 일정에는 미정 문구를 사용. D-Day는 그 자체로 편집 동작을 의미하지 않음 |

태그는 v4 팔레트의 교시 초록, 학교 파랑, 학원 보라, 개인 주황, D-Day 노랑, 날짜 회색을 사용한다. 일정별 대표 아이콘은 펼친 카드의 팔레트 버튼에서 설정한다. 설정은 브라우저에 저장한다. 시간표가 없는 날의 안내는 보조 글자색으로 표시한다.

개인별 숨김, 예외, 중복 판별, 충돌 알림 상세와 일정 편집 흐름은 화면 UX 명세에 둔다. 충돌 표시는 동시 존재를 알리는 상태다. 출처 갱신, 삭제, 구독 해제는 해당 출처의 원본에만 영향을 준다.

## 6. 그룹과 권한

| 구분 | 표현 |
|---|---|
| 학급·학원·스터디 | 학급은 파란 학교, 학원은 보라 건물, 스터디는 초록 목표 아이콘을 사용한다. 구성원 수에는 주황 사람 아이콘을 사용한다. 학년도·학급·그룹 ID의 값은 오른쪽에 맞춘다. 학년도 값은 `2026`, 학급 값은 `하루고 2-3`처럼 표시한다 |
| 가입 전 | 공개 설명과 규모가 허용된 카드. 학급 그룹은 학년도·학교·학년·반·고유 식별자를 표시. 구성원 명단, 그룹장 프로필 내부 정보는 가입 후 유효 권한에 따라 표시 |
| 가입 신청·승인 | 신청 전·신청 완료·처리 중·완료·오류를 신청자에게 표시. 관리 화면에서는 승인 권한이 있는 사람에게만 신청 행을 표시 |
| 비활성 | 기능 범위 ‘비활성’. 정책 설정 UI에는 이유와 현재 값을 표시할 수 있음 |
| 1:1 | ‘1:1 · 그룹장과 해당 구성원’처럼 데이터 접근자를 설명. DM·쪽지 진입점이나 대화 상대 UI를 제공하지 않음 |
| 활성 | ‘활성 · 구성원 전체’. 개인 상세 통계에는 이 옵션을 제공하지 않음. 학급의 상세 통계 기능은 공유 정책 편집에도 노출하지 않음 |
| 정책 확인 | 목록의 가입을 누르면 가입 정책을 확인한다. 입장을 누르면 해당 그룹으로 이동한다. 이미 가입한 그룹의 공유 범위 확대 확인은 그룹 내부에 들어간 후 연다. 대상·항목·기간·변경 내용을 한 화면에 표시하고 전체 정책을 한 번 확인한다 |
| 범위 축소·확대 | 축소는 즉시 유효. 확대는 해당 구성원 확인 후 유효. 혼합 변경은 먼저 축소를 적용하고 확대는 확인 대기 상태로 둠. 보류·거부 후 그룹에 남을 수 있고 축소를 적용한 기존 범위가 유지 |
| 그룹장 화면 | 구성원별 유효 범위에서 허용된 정보만 제공. 완료·보류 배지, 확인자 수, 상태 필터, 내보내기, 접근 실패 문구 등에 확인 여부를 드러내는 단서 추가 금지 |
| 이양 | 적격 구성원만 선택 대상으로 표시. 확인 화면에 대상과 즉시 승계 및 기존 그룹장 권한 종료를 명시. 현재 그룹장이 실행하면 즉시 승계하고 대상자의 수락 단계를 두지 않음 |
| 신고·숨김·차단 | 신고 대상과 수신 범위를 표시. 그룹 자체와 그룹장 권한 남용은 운영자 직접 신고 가능. 자신의 숨김과 관리자의 게시물 숨김을 접근성 이름과 문구에서 구별. 차단의 구체 효과는 운영 정책에 따라 표시 |

그룹 목록은 화면 너비와 관계없이 한 열로 표시한다. 그룹 카드와 그룹 상세는 유형별 색상 아이콘과 이름을 같은 줄에 표시하고 분류·규모 태그를 그 아래에 둔다. 그룹 목록의 규모는 가입 여부와 관계없이 **1, 2+, 5+, 10+, 20+, 50+, 100+, 200+, 500+, 1k+**에서 실제 인원수 이하의 가장 큰 구간을 사용한다. 4명은 `2+`, 27명은 `20+`, 1,350명은 `1k+`다. 스크린 리더에는 ‘구성원 20명 이상’처럼 읽힌다. 가입 전 검색 응답·보조 텍스트·DOM·분석 이벤트에도 정확한 수가 포함되지 않는지 점검한다. 가입한 그룹 내부에서는 ‘27명’처럼 실제 수를 표시한다. 집계 대상과 0명 처리처럼 기획에서 정하지 않은 값은 데이터·권한 명세에서 결정한다.

| 기능 | 학급 기본값 | 학원 기본값 | 스터디 기본값 |
|---|---|---|---|
| 시간표·일정 배포 | 학교 자동 연동 | 활성 | 비활성 |
| 그룹 이야기 | 활성 | 1:1 | 활성 |
| 구성원 총 공부 시간 | [보류] | [보류] | [보류] |
| 개인 상세 통계 | 허용하지 않음 | 1:1 · 상한 1:1 | 비활성 · 상한 1:1 |

그룹 개설 UI는 학생에게 학급·스터디, 교사에게 자신의 계정에서 선택한 종류만 제시한다. 학원 그룹의 강한 관리 권한은 운영 주체 확인 뒤 제공한다. 1:1 이야기의 작성·댓글 범위, 회원별 공부 시간 측정·집계·공개, 이양 시 기존 확인 효력, 강한 정책의 판정 기준, 신고 열람 및 제재 상세는 관련 명세에서 공급한다.

## 7. 이야기·개인정보와 학습 기록

| 상황 | 컴포넌트 규칙 |
|---|---|
| 그룹과 광장 | 이야기에서 실제 가입 그룹과 전체 회원 광장을 각각 탐색하고 작성. 그룹은 유효 정책이 적용된 접근 범위를, 광장은 ‘광장 전체 회원’을 글 상단의 태그에 표시 |
| 글 작성과 재공유 | 작성 제목·입력 영역 앞에 대상을 표시한다. 모바일은 화면 아래에서 전체 너비 카드로 열리며 본문은 카드 여백 안의 테두리 없는 영역에 입력한다. 같은 공간 대상 리포스트·재공유만 권한에 따라 표시. 링크·첨부·카드 미리보기와 직접 진입에서도 원본 범위 적용 |
| 프로필 | 공개 화면에는 닉네임·핸들. 학교·학년·반·번호의 공개 프로필 필드나 자동 표시를 제공하지 않음. 그룹의 공개용 식별 정보와 개인 공개 프로필을 구별 |
| 문제·풀이 첨부 | 게시글 안에 수학 아이콘·실제 수식이 있는 문제 카드와 ‘물음샘에서 풀기’를 표시한다. 그룹에서 연 문제의 재공유 대상은 원본 범위를 유지. 접근할 수 없을 때는 콘텐츠 미리보기 없이 안내 |
| 외부 링크와 개인정보 | 허용된 링크는 이동 전에 목적지 도메인과 외부 이동을 알리고 취소를 제공. 글 작성 또는 공유에서 개인정보 공개 경고에 내용을 특정하고 수정할 입력 지점과 연결. 탐지·제한·공개 순서는 운영 정책 적용 |
| 비로그인 | 물음샘 전용 탐색. 로컬 기록은 ‘이 브라우저에 저장’으로 표시. 백업/복구 조작은 로컬 기록에 연결. 가입·로그인 안내 예제 ‘로그인하기 전에 쌓은 기록은 계정으로 옮겨지지 않습니다’는 기획의 제안 상태 |
| 검증 기록 | 로그인 상태의 포인트·XP 교차 검증과 검증 기록 갱신은 서버에서 처리한다. 일반 결과에는 지표 카드만 표시한다. 서버가 부정한 방법을 감지해 검증 기록 반영을 거절한 경우에만 “점수·XP가 일치하지 않아 이번 학습 결과가 검증 기록에 반영되지 않았어요.”를 경고로 표시한다. 통신 실패와 미확인 상태는 부정 감지 판정으로 분류하지 않는다. |
| 기록 오류 | 서비스 응답에서 확인 가능한 단계와 반영 상태를 안내. 오류 문구를 부정행위 판정으로 치환하지 않음. 재시도 표시·데이터 복구·중복 제출 대응은 학습 기술 명세가 정한 동작만 표시 |

## 8. 검증 기준

| 검증 | 통과 조건 |
|---|---|
| v4 회귀 | 버튼을 라벨형과 아이콘형으로 분류하고 v4 조작 상태, 2px 선과 깊이, 글자 대비를 검사. 오늘 구분선·학습 현황의 선이 같은 토큰을 읽는지 확인. 태그와 아이콘 타일 규칙, 스위치 오프·온, 꾸밈 없는 range 조작, KaTeX·종이 테마 회귀 확인 |
| 화면 폭과 확대 | 320·393·600·719·720·900·1080·1440px의 5탭. 모바일 밑줄과 PC 파란 2px 테두리를 확인. 라벨 오프 5개 아이콘, 온 5개 라벨. 선택 전후 탭과 이야기 오른쪽 버튼의 좌표·터치 영역 고정. 모바일의 네 항목을 2×2로 배치하고, 행동 카드와 전역 탭바 사이 간격 및 행동 카드의 단일 표면을 검사. 다섯 화면 제목의 상단 여백과 단일 대화상자 버튼의 전체 너비를 확인. 200% 글자 확대, 400% 페이지 확대에서 본문 재배치, 긴 닉네임·시간·날짜·출처의 줄바꿈, 바·키보드와 포커스 겹침 검사 |
| 테마와 포커스 | 밝게·어둡게·종이·시스템. 일반·선택·활성·오류·경고의 실제 조합과 채움 뒤 아이콘 대비를 픽셀 기준으로 확인. 키보드만으로 이동, 닫기와 확인의 접근성 이름, 모달 탈출·복귀, 강제 색상·모션 감소, TalkBack·VoiceOver 및 데스크톱 스크린 리더로 이름과 상태 확인 |
| 일정과 엄지 접근 | 시간표에서 수업·점심·방과후가 시작 순으로 나타남. 오늘은 현재 수업만 파란 외곽선과 기본 펼침 상태를 가짐. 다음은 ‘오늘’을 중앙에 놓은 파란 단일 구분선을 사용. 320px에서 교시·출처·D-Day 태그가 필요한 만큼 줄바꿈. 오늘에는 시간표만, 다음에는 날짜별 일정이 나타남. 두 출처 모두 남고 읽기 전용과 편집 권한이 구별됨. 현재 행동에 한 손으로 닿으며 탐색과 중복 동작이 생기지 않음 |
| 학습과 필기 | 일반 화면에서 바로 진입, 집중 중 전역 탭 숨김, 드로잉 중 화면 위치 유지, 지우개 반영, 답안 키보드 선택, 채점 알림, 종료 뒤 화면과 맥락 복귀. 일반·결과·수학·영어에 동일한 스타일시트 적용 여부와 풀이 도구의 24px 아이콘, 2px 조작선, 테마별 패널 표면을 브라우저의 계산된 스타일로 확인. 320px 및 425px 화면에서 닫기·답안·북마크가 한 행인지, 답안 포커스 시 전체 폭으로 확대되는지 확인. 720px 이상에서 답안·건너뛰기·공유가 문제 아래 같은 행에 있고 태그가 제목 행에 있는지 확인. 필기구 선택 테두리와 모바일 난도 라벨 설정의 기본값·저장·복원 확인. 짧은 화면과 화면 키보드를 띄운 상태에서 행동 바·답안·스크롤 끝에 접근 가능해야 함. 기기 펜·터치·마우스 각각 검사 |
| 그룹 권한 | 가입 전·후 크기, 그룹 분류·역할·상한, 축소 즉시 적용·확대 확인 전까지 유효 범위 유지, 혼합 변경, 보류 구성원의 잔류, 그룹장 이양 직후 권한 전환. 제품에서 권한 없는 데이터가 화면·접근성 트리·직접 접근·검색 응답·내보내기에 나타나지 않는지 검사 |
| 이야기와 개인정보 | 미가입 그룹·광장·1:1에 대한 각 사용자 역할의 접근 검사. 공간 밖 리포스트와 미리보기 차단, 글 작성 범위 확인, 공유 학습 진입, 신고/숨김/차단과 외부 이동, 공개 프로필 누출 검사 |
| 학습 기록 | 비로그인 상태에 물음샘만 표시. 로컬 가져오기 후에도 계정 수치 그대로. 정상 결과에는 지표 카드만 표시. 부정한 방법으로 기록 반영이 거절된 경우에만 경고 표시. 검증 전 공인 합계 변경 금지. 백업·실패·동기화의 실제 정책은 기술 명세로 검증 |

함께 제공한 HTML은 상호작용 설계 예제다. 오늘·다음의 배열, 다섯 탭, 테마, v4 조작 상태, 집중 학습과 공유 범위, 가입·권한 대화상자와 관리 컴포넌트를 비교할 수 있다. HTML은 고정된 수학·영어 예제의 입력, 암기 응답, 필기와 화면 전환을 시연한다. XP는 정답당 1의 예제값, 콤보는 연속 정답의 최댓값, 정확도는 채점된 응답 중 정답 비율이다. 열람만 한 항목은 정확도 집계에서 제외한다. 검증 기록 경고는 ‘나 → 디자인 예제 → 상태 샘플 → 검증 기록 경고 예제’에서 확인할 수 있다. 예제 그룹의 가입·승인·인원과 반응 숫자는 시연용이다. 새 그룹은 로컬 예제에서 생성하고 브라우저에 저장한다. 실제 계정, 서버 권한 집행, 게시·신고 처리, 공인 검증 연동은 제품 구현 검증 대상이다.
