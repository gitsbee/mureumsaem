# 물음샘 이름 검색

2026-11-23 확인 시도. 현재 실행 환경의 외부 접속 제한으로 아래 서비스의 실제 결과 목록을 열지 못했다. 등록 상표, 출원 중 상표, 서비스·계정 중복 여부는 미확인이다.

| 서비스 | 확인할 검색어와 범위 |
| --- | --- |
| [KIPRIS](https://www.kipris.or.kr/) | 물음샘, 무름샘, 물음 샘, 무름 샘을 각각 검색한다. 제9류 앱·다운로드형 교육 소프트웨어, 제41류 교육·학습 서비스, 제42류 온라인 소프트웨어·SaaS의 지정상품과 권리 상태를 확인한다. |
| [Google Play](https://play.google.com/store/search?q=%EB%AC%BC%EC%9D%8C%EC%83%98&c=apps&hl=ko&gl=KR) · [App Store](https://www.apple.com/kr/app-store/) | 한국 스토어에서 ‘물음샘’, ‘무름샘’과 예상 로마자 표기를 검색해 앱 이름과 개발자 이름을 확인한다. |
| [GitHub](https://github.com/search?q=%22%EB%AC%BC%EC%9D%8C%EC%83%98%22&type=repositories) | 두 이름을 검색하고 로마자 후보도 저장소, 사용자·조직에서 따로 찾는다. |
| [Instagram](https://www.instagram.com/) · [Threads](https://www.threads.com/) · [YouTube](https://www.youtube.com/) · [X](https://x.com/) | 앱 안에서 한글 표시 이름과 로마자 핸들을 각각 확인한다. 검색 노출과 핸들 등록 가능 여부를 따로 확인한다. |

KIPRIS에서 유사 결과가 있으면 출원·등록번호, 지정상품, 상태를 기록한다. 검색 결과와 실제 상표 사용 가능성은 개별적으로 확인해야 한다.
