# 물음샘 통합

물음샘·수학·영어는 기존 Pages 주소 아래에서 같은 상단 바와 Firebase 계정을 사용한다. 물음샘의 담벼락에는 기존 게시물·댓글·리포스트를 그대로 표시한다.

## 코드 구성

- `src/forge.css`의 문제공방 원본 디자인이 공통 화면, 학습 화면과 담벼락을 렌더링한다. `src/pulim.css`에는 서비스 전환, 담벼락과 암기마스터의 구간 미리보기·연습에 필요한 배치가 있다. 버튼은 입체 조작과 평면 보조 조작, 아이콘은 기본 24px과 태그 18px으로 나뉘며, 상태 태그는 공통 팔레트의 역할 색을 사용한다.
- `src/learning/engines/`에 수학과 영어의 원래 학습 엔진을 둔다. 두 과목은 React 화면과 같은 문서에서 실행하며 엔진 어댑터가 화면 전환·임시 저장·채점 이벤트를 연결한다. 원래 문제 생성, 해설, 필기, 단어장과 복습 기능을 사용한다.
- 평소에는 같은 상단 바를 사용하고 풀이 중에는 과목의 풀이 도구를 표시한다. 화면 모드는 모든 화면에서 공유하며 초기 HTML의 배경부터 적용한다. 수학 수식은 번들에 포함한 KaTeX로 표시한다.
- 문제공방의 오늘의 문제는 수학의 원래 학습 화면과 문제 생성기를 사용한다. 이전 공통 문제의 결과와 공개 점수에 대한 데이터 경로는 호환을 위해 유지한다.

## 데이터와 운영

| 위치 | 내용 | 공개 범위 |
| --- | --- | --- |
| `users/{uid}/learning/{id}` | 과목·문제명·학습 방식·결과·시각 | 본인 |
| `users/{uid}/learningDays/{day}/subjects/{subject}/answers/{index}` | 오늘의 문항별 첫 결과 | 본인 |
| `pulleemDays/{day}/subjects/{subject}/scores/{uid}` | 사용자가 공개를 선택한 정답 수 | 전체 |

서버 규칙은 한국 날짜, 문항 번호, 최초 제출, 소유권과 세 문항의 합계를 검사한다. 정오 판정은 브라우저에서 수행하므로 랭킹은 참여용으로 운영한다. 계정의 풀이 요약과 오늘의 결과를 연동하며, 초안·필기·과목 내부의 복습 상태는 이 브라우저에 보존한다.

Firebase 콘솔에서 `firestore.rules`를 게시한 다음 Pages 배포 결과를 확인한다. 운영에서는 두 브라우저에서 같은 계정으로 로그인해 새 풀이 기록이 양쪽에 나타나는지 확인한다.
