# 하루이음 스터디

**고등학생부터 N수생까지, 흩어진 하루를 하나로 잇다**

하루이음 스터디는 시간표와 일정, 수학·영어 학습, 그룹 이야기를 연결하는 학생용 PWA입니다. 기존 물음샘 이메일로 로그인할 수 있으며 물음샘은 학습 탭의 이름으로 이어집니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 오늘 | 하루 일정과 학교 시간표·급식을 살펴보고 개인 필기를 작성합니다. |
| 다음 | 시험·과제·학사일정을 날짜순으로 보고 일정에 연결된 과목을 엽니다. |
| 물음샘 | 수학 문제 풀이·필기와 영어 단어 연습, 오답·북마크 복습을 이용합니다. |
| 이야기 | 공개된 범위에 따라 가입한 그룹의 글을 읽거나 광장에 참여합니다. |
| 나 | 프로필, 학교·학급 설정, 풀이 기록과 앱 설정을 관리합니다. |

학교 정보는 선택 사항이며, 시간표·급식·학사일정은 학교 연동을 구성한 환경에서 제공됩니다. 로그인 없이 물음샘을 이용할 수 있습니다. 비로그인 상태에서 만든 기록은 이 브라우저에 남고, 로컬 백업도 계정의 풀이 기록에 합산되지 않습니다.
