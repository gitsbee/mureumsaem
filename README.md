# 물음샘

**한 문제에서, 함께 푸는 질문으로.** 물음샘은 수학과 영어를 연습하고, 막힌 문제를 담벼락에서 바로 질문하는 학습 공간입니다.

[물음샘 시작하기](https://gitsbee.github.io/Pulim/) · [소개](https://gitsbee.github.io/Pulim/About/) · [도움말](https://gitsbee.github.io/Pulim/#/help)

## 무엇을 할 수 있나요?

- **수학**에서 공통수학의 단원과 난이도를 골라 문제를 풀어 보세요. 풀이 여백에 직접 쓰고 채점과 해설을 확인할 수 있습니다. ‘오늘의 문제’로 학습을 시작하거나, 기록에서 틀린 문제를 다시 풀 수 있어요.
- **영어**에서 단어 뜻을 떠올리는 암기, 보기에서 고르는 선택, 직접 입력하는 스펠 연습을 할 수 있습니다. 틀린 단어와 북마크는 기록에서 다시 만나 볼 수 있어요.
- **담벼락**에는 문제 화면의 **이 문제로 질문하기**로 문제를 첨부할 수 있어요. 질문을 올리고, 다른 사람의 풀이에 댓글을 남겨 보세요. 좋아요·싫어요·리포스트로 반응할 수 있습니다. 검색은 현재 불러온 글의 본문, 작성자와 태그를 대상으로 합니다.

## 처음이라면

1. [홈](https://gitsbee.github.io/Pulim/)의 ‘한 문제 맛보기’에서 수학과 영어를 한 문제씩 체험해 보세요.
2. 상단에서 원하는 과목을 열고 연습할 범위를 고르세요. 로그인 없이도 연습할 수 있습니다.
3. 기기 간 풀이 결과를 확인하거나 담벼락에 참여하려면 프로필 아이콘을 눌러 가입하세요. 가입할 때 공개 프로필에 사용할 핸들과 닉네임을 정합니다. 로그인과 비밀번호 재설정에는 가입한 이메일을 사용합니다.

로그인 후 풀이 결과와 제출한 답안은 각 과목의 **기록** 탭에서 확인할 수 있습니다. 수학에서 기록한 문제 지문과 풀이 시간도 동기화됩니다. 필기, 진행 중인 문제, 복습 상태는 사용한 브라우저에 남습니다. **프로필 → 내 정보 관리**에서 브라우저에 저장된 수학·영어 기록을 백업하거나 복원할 수 있어요.

설정에서 밝게·어둡게·종이 테마와 효과음, 펜 입력, 세벌식 390을 조정할 수 있습니다. 글과 댓글은 공개됩니다. 메뉴에서 신고하거나 글을 숨기고 작성자를 차단할 수 있어요. 숨김과 차단은 프로필에서 해제할 수 있습니다.

물음샘 코드와 디자인에 기여하려면 [저장소 작업 지침](AGENTS.md)과 [디자인 시스템 v4 가이드](docs/design-system/v4/README.md)를 참고하세요.

향후 개발 제안과 우선순위는 [개발 로드맵](docs/ROADMAP.md)에서 확인할 수 있습니다.

도메인·Firebase·개발 미리보기 설정과 기록 이전은 [배포 문서](docs/DEPLOYMENT.md)를 참고하세요.
